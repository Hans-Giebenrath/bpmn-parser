= Installation

The tool is in an early stage and is not yet available on crates.io or as a pre-built binary.

. Clone the repository, and
    link:https://doc.rust-lang.org/cargo/getting-started/installation.html[get `cargo`].

You can compile a `file.bpmd` via `cargo run --build release -i file.bpmd -o file.svg -f svg`. The .svg file is the final image.
You can also create a BPMN file by using `-o file.xml -f xml` (instead of `-o file.svg -f svg). These you can then import into your regular BPMN editor. However, my focus is currently on the SVG export, hence not all features might be present in the BPMN exporter.
